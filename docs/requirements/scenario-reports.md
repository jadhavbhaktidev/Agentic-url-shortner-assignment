# Required Scenario Reports

## Greenfield

Create URL lifecycle, redirect, and analytics modules from an empty confirmed repository. Gate design approval, then implement backend and frontend in parallel once the OpenAPI contract is stable; synchronize at integration and E2E validation.

## Brownfield

Before changing an existing codebase, the Brownfield Analysis node inventories controllers, services, persistence, migrations, UI clients, tests, and deployment configurations. It produces an impact, regression, migration, and rollback plan. No destructive migration or API break proceeds without approval.

## Ambiguous requirement

Example: “show analytics.” The Ambiguity agent records whether this means total clicks, event-level data, real-time updates, access control, retention, and PII. It selects only reversible defaults and raises an approval request for public behavior.
